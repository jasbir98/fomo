# Fomo — Product/UX audit & improvement plan

## Context
The user asked for a top-tier product designer + PM review of Fomo (Edinburgh free/cheap/deals PWA,
pivoted from the Roameo trip planner on 2026-09-12). Google/Apple login are known-broken and excluded.
Method: walked the running app at 375px (Feed tabs, What's on, Deals, deal detail, Free, Explore,
Reels, Fomo chat, Profile) at 00:47 BST Tue 15 Sep 2026, plus two code audits. Findings below are
ranked by user impact; the roadmap at the end groups them into shippable phases.

The product's core promise is **"trust me, this is real and it's happening now."** Every P0 below is
something that breaks that promise.

---

## P0 — Breaks trust (wrong, stale or broken info)

1. **Expired offers shown as live, dated today.** "EIF £10 Give it a Go Tickets" (2026 Festival ran
   in August) is on /deals and its detail page says `Tue 15 Sep 2026 · When: Every day · Checked 2d
   ago`. Same for EIF Under-18 / Under-30 / Arts-worker concessions, Book Festival concessions. "Checked"
   only proves the page exists, not that the offer is current.
   → Require an `ends_on`/season window for festival-bound rows; hide past-window rows in the feed
   query; verification must re-check dates, not just URL liveness.
2. **False urgency.** Hero reads "Royal Botanic Garden **Daily** Guided Walks — **today only.**" under
   "Fomo Pick · Last Chance". Weekly/daily recurrences expand one day at a time so every day is its
   own "last day" (`lib/happenings/occurrence.ts:280` → `lib/happenings/hero.ts:126` →
   `lib/happenings/format.ts:562`, `HappeningHero.tsx:82`) — and it gets a ranking bonus for it.
   → Compute last-chance from the *series* end, never from a single recurring occurrence.
3. **"Tonight" for a 12:30 lunchtime slot, in device timezone.** `lib/events/format.ts:40,61` labels
   any same-day event "Tonight" and uses `toLocale*(undefined)` (phone TZ) while happenings use
   Europe/London. → "Today · 12:30" / "Tonight · 19:00" split at ~17:00, always `CITY.timezone`.
4. **Things that already ended stay under "Today"; things in progress vanish.** Happenings compared by
   calendar day only (`occurrence.ts:261`); provider events filtered `starts_at >= now`
   (`lib/db/events.ts`, `app/api/feed/route.ts:194`) so a gig that started 20 min ago or a multi-day
   exhibition disappears. → Use `ends_at > now` (or start+default duration) for both; add a
   "Happening now" treatment.
5. **Misfiled "Free".** Free Any Time lists "Free Entry at National War Museum" (needs a paid Castle
   ticket), "EIF Tickets for Good" (restricted eligibility, festival over), "Young Scot NEC discounts"
   (a card, not a thing to do). → `is_free` must mean £0 for anyone, no prerequisite purchase; move
   the rest to Deals with eligibility.
6. **Non-deals in Deals & Offers.** "£99 Player Pass Season Ticket … **£99 off**" (it *costs* £99),
   "Spartans season ticket **£200 off**", "National Museums Family Membership £66 off", Nando's NHS
   (national chain, not Edinburgh), "Young Scot NEC rail travel". Badge "NATIONAL EVENT" is jargon.
   "EIF Under 30" is tagged "Under 26s". `saving_amount` is being rendered where `price` should be.
   → Data audit pass + a render rule: only show "£X off" when a reference price exists.
7. **Errors masquerade as "nothing on" or infinite loading.** Home feed failure → skeleton forever
   (`app/(shell)/page.tsx:89-93,465`); route catch returns empty sections → "Nothing lined up"
   (`route.ts:891-900`); detail network error → "We couldn't find this deal". No `res.ok` checks.
   → Real error state with retry on every feed page.
8. **Hero images blocked.** `http://` image URLs (e.g. stockbridgemarket.com) violate CSP
   `img-src https:` → broken/blank heroes. → Upgrade to https or proxy via `media-proxy`, fall back
   to category art.
9. **Hard sign-in wall before any content** (`proxy.ts`). A discovery app for "what's free tonight"
   shows 3 intro slides then demands an account; shared links also require sign-in. This is the
   single biggest growth killer. → Make Feed/Deals/Free/Explore/detail pages public; ask for sign-in
   only on Save, Notify me, chat.

## P1 — Core experience gaps

10. **Fomo AI chat is still the trip planner and knows nothing about Edinburgh deals.**
    Mode tabs "Translate / Plan / Explain / Recommend"; chips "Nav to meeting", "Lunch near Ginza",
    "Add this to my itinerary" (`lib/fomo-ai.ts:279`); system prompt says "traveler", "Travel DNA",
    `propose_itinerary_item`, PLAN mode (`app/api/chat/route.ts:102-277`); **no happenings/events
    grounding** in the route. Translate icon in header. → Rebuild as "Ask Fomo": one mode, tools that
    query happenings/events/places, answers render the app's own cards, Edinburgh chips
    ("Free tonight", "Student deals this week", "Rainy day under £10").
11. **Profile is trip-era.** "Walking: Happy to walk · Pace: Packed · Rhythm: Night owl", "Fomo Rules",
    "Reset practicalities", tier "Explorer", default name "Fomo user", links to `/setup/travel-dna`,
    `/setup/always-remember` ("future itineraries"). Missing what matters here: **who am I for deals**
    (student / EH resident / under-26 / over-60 / NHS / Young Scot) and **neighbourhood**.
    → Replace prefs with an eligibility + interests profile that auto-filters and badges "You qualify".
12. **Saved is buried** inside Profile (nav slot went to Deals). Happening detail pages have **no save
    button**; list-card save only on event rows, always starts unsaved (`FeedListCard.tsx:71,96`).
    Saved doesn't expire past items. → Save on every card + detail page; Saved reachable in ≤1 tap
    (header bookmark icon); split "Upcoming / Past".
13. **No "for me" personalisation.** One global deterministic hero for every user, ignores the tab
    (`route.ts:8,696`), never rotates, can't be dismissed. Book-early hero has `reason: null`.
    → Rank by eligibility + interests + distance + time-of-day; always show a one-line "why".
14. **Book Early promise is hollow.** Tagline "Things that sell out fast", but list is padded with
    ordinary Skiddle events all labelled "ON SALE NOW" + "Book now" (`route.ts:611-616`). Hero is
    "Edinburgh Cocktail Week VIP Pass £20". Notify-me / big on-sale alerts need deploy + push.
    → Only source-backed `sellout_risk` items; empty is fine. Show *why* it sells out.
15. **Thin "What's on".** 4 items for Today & Tomorrow in a capital city, one duplicated ("Back To
    School 50% off" on both days), "Pat Hamilton" with no genre/price/description, Category chips
    "Music / Other". → Collapse series into one card with "Today + Tomorrow"; require a one-line
    what-is-it; expand sources (free exhibitions, parkrun, markets, comedy, museum late openings).
16. **Detail pages miss conversion basics.** No add-to-calendar on happenings, no explicit "Ends
    <date>", CTA defaults to "Claim Offer" even for a free museum (`happening/[id]/page.tsx:179`),
    "Where" is a placeholder icon (`:591`), promo-code copy fails silently (`:133`), no price field on
    happenings, event share text says unpriced = "Free" (`event/[id]/page.tsx:122`). Sticky CTA uses
    `bottom-[64px]` without safe area → hidden behind nav on iPhone.
17. **Reels don't serve the promise.** 0 Edinburgh reels → falls back to "Near Edinburgh", first reel
    is Airdrieonians at Excelsior Stadium (Airdrie). LIKE/SKIP swipe mechanic is unexplained and
    feeds nothing visible. → Hide Reels tab until there's Edinburgh content, or make every reel link to
    a live happening/place with its price; otherwise replace the nav slot with Saved.
18. **Explore relevance.** "160 nearby" shown without location permission; Glenkinchie Distillery
    (East Lothian, ~25 km) in the top 5; the pin legend (Place/Deal/Event/Free) duplicates the layer
    chips; map + neighbourhood chips + category chips + collections stack before any result.
    → Default sort by "open now + cheap", honest "in Edinburgh" count, collapse filters into a sheet.

## P2 — Polish, IA and consistency

19. **Header noise.** "Fomo / FEED" sub-label, "EH · Edinburgh" pill opening a one-city picker
    ("more are on the way"), weather chip "rainy 18°" on a red/pink tint that reads as an error.
    → Drop city picker; weather neutral tint and make it do something (tap → "rainy-day ideas").
20. **Duplicate / orphaned pages & naming drift.** /whats-on vs /events ("What's On"), /discover/[intent]
    and /experiences (Viator "Day Trips") orphaned, /kit and /fomo/translator reachable; "Now" vs
    "Today & tomorrow" vs "Happening Today & Tomorrow"; "Book early"/"Book Early", "Free any time"/
    "Free Any Time"; "Claim Voucher Code"/"Promo Code"/"Code at checkout"; Deals subtitle "valid
    whenever you go" is false for dated deals. → One glossary, delete or redirect orphans.
21. **Deals IA.** Deals isn't on Home; the hero deal is removed from /deals (`route.ts:485,851`) so the
    best deal is unfindable in Deals. Venue cards show "2 offers" but no headline offer text. No sort
    (nearest / biggest saving / ending soon) and no "near me".
22. **Accessibility.** Cards are `div role="link"` wrapping real buttons/links (`NavCard.tsx:29`,
    `FeedListCard.tsx:115`) — no open-in-new-tab, aria-label hides price; 24–32px tap targets
    (`page.tsx:400,363`, detail `:557,565`); 9–10px text (`FeedListCard.tsx:40`,
    `DateFilterRow.tsx:91`); no `role="status"` on spinners; pulses ignore `prefers-reduced-motion`.
23. **Performance.** /api/feed rebuilds hero + year of events + all places sequentially on every tab
    switch; /deals, /free, /book-early pay for the What's-on merge then discard it; detail route loads
    every live happening to find siblings; every page is a client component → skeleton-first paint.
    → Per-section endpoints, parallel queries, cache by window, server-render first section.

### Additional findings (map / saved / push / PWA / place audit)

24. **Chat invents data.** `suggest_place` asks the model to fabricate an Unsplash image URL and rating
    (`app/api/chat/route.ts:241-252`); chat cards have no id/link, only a "View" modal
    (`fomo/page.tsx:872-879`); "Ask Fomo" from an item sends only its name (`:259`). Folds into #10.
25. **Deals, free things and book-early can't be saved at all.** No `happening` saved-item type
    (`lib/types.ts:347`); Explore hides Save on happening pins claiming the detail page has it
    (`lib/explore/pin-style.ts:55`, `ExploreSheet.tsx:45`) — it doesn't; reel saves without a place are
    silently dropped (`ReelViewer.tsx:467` vs `app/api/saved/route.ts:180`); every saved card button says
    **"Add to today"** (`saved/route.ts:121,145`); load failure = empty state. Folds into #12.
26. **Place page fabricates / trip leftovers.** Shows "Open now" when there's no badge
    (`place/[id]/page.tsx:185`), "Station" + train icon + "prefecture" (`:250,266`), "near your route",
    reviewer fallback "Traveler".
27. **Notifications half-built.** Notify me hidden if VAPID key unset; no Notify on Skiddle/Ticketmaster
    Book Early rows (`BookEarlyCard.tsx:169`); can't unsubscribe (`NotifyMeButton.tsx:46`); iOS users
    learn "Add to Home Screen" only after tapping; Profile toggles "Event reminders / New AI suggestions /
    Weekly digest" + 3 privacy toggles persist but nothing reads them (`profile/page.tsx:737-844`) —
    fake settings.
28. **Location permission prompt fires on first load** with no pre-prompt (`lib/geo.ts:244`) — a denial
    usually sticks, killing "near me" forever. → Ask in context ("Show what's near me").
29. **Map mechanics.** No clustering (up to 300 DOM markers rebuilt per selection, `MapCanvas.tsx:162`);
    "Everything" caps 75 pins/layer of ~3.4k; place badge shows rating not price, contradicting the
    cheap promise; fixed 52vh map, no list/map toggle; missing-token fallback shows dev text and centres
    on **Tokyo** (`MapCanvas.tsx:23,241`).
30. **PWA promises that aren't true.** Offline page: "your saved things will be here when you're back" —
    SW caches no pages/API (`public/sw.js:12`); cache name frozen `roameo-shell-v1` so updates never
    ship to existing installs; no install prompt; icons `"any maskable"` get cropped.
31. **Safe-area overlap.** Chat composer and all sticky CTAs use `bottom-[64px]` while nav adds
    `pb-safe` → overlap on iPhones with home indicator (`fomo/page.tsx:578`). Disabled "coming soon"
    photo/voice buttons waste composer space.
32. **Chat failure UX.** 429 replaces bubble, isn't persisted, composer stays active; no remaining-quota
    hint; user message saved before reply so reload shows unanswered questions; switching mode clears
    the thread (looks like data loss).

## User decisions (2026-09-15)
- #9 → **Open browsing**, shared links included. Sign-in is asked for only on Save, Notify me and Ask Fomo, and returns the user to the item.
- #17 Reels → **out of scope**. The user is adding Edinburgh reels; don't change the Reels code.
- Commit and push to `jasbir98/fomo` main after each phase, then continue. Never commit
  `scraper/data/batch_progress_edinburgh.json`.
- Separate side task: the Instagram scraper picks reels out of the grid before visiting posts (in progress).

## Roadmap (recommended order)

**Phase 1 — Trust (P0 1-8).** Data + logic fixes: expiry windows, series-aware urgency, London-TZ time
labels with Today/Tonight split, ends_at filtering, free/deal classification audit, error states,
https images. Files: `lib/happenings/{occurrence,hero,format,groups}.ts`, `lib/events/format.ts`,
`lib/db/events.ts`, `app/api/feed/route.ts`, feed pages, `scraper/weekly_edinburgh.py` verification.

**Phase 2 — Open the door (#9, 12, 25, 28).** Public browsing in `proxy.ts` (keep `/api/saved`,
`/api/push`, `/api/alerts`, `/api/chat` gated), sign-in prompted from Save/Notify/Ask and returning to
the item; `happening` saved type + Save on every card/detail page with correct initial state; Saved one
tap away; contextual location pre-prompt.

**Phase 3 — Fomo knows me (#10, 11, 13, 24, 32).** Eligibility profile (student / EH resident /
under-26 / over-60 / NHS / Young Scot) + interests replaces Travel DNA/practicalities/rules; ranking
uses it; "You qualify" badges. Rebuild Ask Fomo: single mode, tools that query happenings/events/places
and return real ids rendered as the app's own cards; Edinburgh chips; delete Plan/Translate/Emergency
modes, itinerary tools, translator route, invented images/ratings; fix failure/429 persistence.

**Phase 4 — Content & conversion (#14-18, 26, 27, 29).** Honest Book Early, series collapse,
detail-page calendar/ends/price/where; remove fabricated "Open now" + trip fields on place page;
finish notifications (unsubscribe, events, iOS install guidance) and delete fake Profile toggles;
Reels decision; Explore relevance + clustering + price badges.

**Phase 5 — Polish (#19-23, 30, 31).** Header, glossary + orphan cleanup (/events, /discover,
/experiences, /kit, /setup/*), Deals sort/near-me, a11y + safe areas, perf, truthful offline page +
versioned SW cache.
